## 🛠️ Tecnologias Utilizadas

Este projeto foi construído do zero como parte de uma aula de desenvolvimento web, onde cada aluno teria que construir seu propio portfolio utilizando as tecnologias fundamentais da web:

- **HTML5:** Estruturação semântica e acessibilidade.
- **CSS3:** Estilização, layout responsivo (Flexbox/Grid), animações e modo noturno.
- **JavaScript (Vanilla):** Manipulação do DOM, filtros dinâmicos de projetos e animações de rolagem (Intersection Observer).


## ⚙️ Funcionalidades em Destaque

- **Responsividade:** Layout adaptável para dispositivos móveis, tablets e desktops.
- **Filtro de Projetos:** Separação visual dos trabalhos por categoria (Web, Embarcados, etc.).
- **Animações de Scroll:** Elementos que surgem suavemente conforme o usuário navega pela página.
- **Navegação Fixa:** Menu que acompanha a rolagem para facilitar o acesso às seções.
